# Needle model files

Model binaries are intentionally not bundled in this repository ZIP.

Copy your `.cact` files here. Expected filenames are listed in
`configs/needle_models.json`. The 320-case summary includes base Needle and all
fine-tuned variants used in the experiment.

Example:
```bash
cp /path/to/needle2_base.cact models/needle/
cp /path/to/needle_rpi_ft08_ep3.cact models/needle/
```
